# سرور اشتراک لایسنس فاکتورخوان

> این سرور ** نباید در گیت‌هاب عمومی منتشر شود**؛ آن را روی سرور privata شرکت خود میزبانی کنید و به مشتریانی که اشتراک یک ساله می‌گیرند، فایل لایسنس صادر کنید.

## راه‌اندازی سریع
```bash
cd licensing_server_example
python server.py
```
سرور روی `http://0.0.0.0:8080` اجرا می‌شود.

## نقاطیات API
- `POST /validate` — بدنه: `{ "license": { ... envelope ... }, "hwid": "..." }` -> پاسخ: `{ "valid": true/false, "message": "...", "days_remaining": N }`
- `POST /issue` — (admin) ساخت فایل لایسنس امضا شده و رمزنگار شده برای مشتری.

## कैसे فروش اشتراک بدهید
1. مشتری یک سال اشتراک را خریداری می‌کند.
2. شما از سرور vlastní، فایل لایسنس tailored با expire_date = ۱ سال و hwid دستگاه مشتری می‌سازید.
3. فایل لایسنس را به مشتری می‌دهید؛ او در برنامه دکمه «بارگذاری فایل لایسنس» را می‌زند.
4. برنامه اعتبار را آفلاین بررسی می‌کند؛ بعد از اتمام یک سال، برنامه خودکار قفل می‌شود (حتی بدون اینترنت).
