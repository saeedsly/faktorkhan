# نصب فاکتورخوان **بدون اینترنت** (بستهٔ کامل ویندوز)

اگر روی سیستم مقصد اینترنت نیست — یا `pypi.org` باز نمی‌شود و خطای
`Read timed out` می‌گیرید — از **بستهٔ کامل ویندوز** استفاده کنید:

> **`faktorkhan-1.0.0-WINDOWS-PORTABLE.zip`** (حدود ۳۵ مگابایت)

این بسته **همه‌چیز** را در خود دارد:

| داخل بسته | توضیح |
|---|---|
| `python\` | خودِ پایتون ۳.۱۳ ویندوزی (نسخهٔ رسمی Embedded، ۶۴ بیتی) — نیازی به نصب پایتون نیست |
| `python\Lib\site-packages\` | همهٔ کتابخانه‌های لازم، از پیش نصب‌شده |
| `wheels\` | فایل‌های خام کتابخانه‌ها برای ترمیم/نصب مجدد (بدون اینترنت) |
| `backend\` `frontend\` | کد برنامه |
| `START-WINDOWS.bat` | اجرا با یک دوبار کلیک |

یعنی روی یک ویندوز تازه: **نه پایتون لازم است، نه pip، نه اینترنت.**
فقط زیپ را باز کنید و `START-WINDOWS.bat` را اجرا کنید.

---

## گام‌به‌گام (۳ گام)

### گام ۱ — دانلود و باز کردن
زیپ را در مسیری ساده باز کنید، مثلاً `C:\` تا مسیر نهایی `C:\faktorkhan` شود.

- مسیر بدون فاصله و بدون حروف فارسی باشد (نه `C:\Program Files\...`).
- اگر ویندوز پیام «Windows protected your PC» داد: **More info → Run anyway**
  (چون فایل از اینترنت دانلود شده و امضای دیجیتال ندارد).

### گام ۲ — اجرا
روی **`C:\faktorkhan\START-WINDOWS.bat`** دوبار کلیک کنید. باید ببینید:

```
[۱/۴] پایتون همراه بسته: نسخه 3.13.18
[۲/۴] محیط اجرا همراه بسته است (نیازی به نصب نیست).
[۳/۴] کتابخانه‌ها آماده هستند.
[۴/۴] فایل تنظیمات موجود است.
   برنامه در حال اجراست:   http://127.0.0.1:8000
   اطلاعات ورود اولیه در این فایل است:
      storage\OWNER-CREDENTIALS.txt
```

> این پنجرهٔ سیاه را نبندید؛ تا وقتی باز است برنامه فعال است.

### گام ۳ — ورود
مرورگر → `http://127.0.0.1:8000` → ایمیل و گذرواژه از فایل
`storage\OWNER-CREDENTIALS.txt`.

## پرسش‌های رایج

| پرسش | پاسخ |
|---|---|
| روی سیستم مقصد باید پایتون نصب باشد؟ | **نه.** پایتون داخل پوشهٔ `python` هست. |
| اینترنت لازم است؟ | **نه.** حتی نصب هم آفلاین است. فقط «خوانش ابری» به اینترنت نیاز دارد. |
| چه نسخه‌ای از ویندوز؟ | ویندوز ۱۰ یا ۱۱، ۶۴ بیتی (۷ و ۸ هم معمولاً کار می‌کنند). |
| بستهٔ کامل را به مشتری بدهم؟ | بهتر است برای مشتری **`FactorKhan-Setup.exe`** بسازید (یک فایل، آیکن دسکتاپ، بدون پنجرهٔ سیاه). این بسته برای سیستم خودتان/سرور است. |
| فایل `install-log.txt` چیست؟ | اگر مرحلهٔ ۳ خطا بدهد، متن کامل خطا آنجا نوشته می‌شود. |
| چطور کتابخانه‌ها را ترمیم کنم؟ | `python\python.exe tools\install_offline.py --wheels wheels` |
| «پایتون پیدا نشد» می‌دهد؟ | یعنی پوشهٔ `python` کنار `START-WINDOWS.bat` نیست؛ زیپ را کامل و درست باز نکرده‌اید. |

## اگر سیستم پایتون دارد و فقط اینترنت ندارد (بستهٔ سبک‌تر)

فایل **`faktorkhan-1.0.0-WINDOWS-OFFLINE.zip`** (حدود ۲۳ مگابایت) فقط پوشهٔ
`wheels` را دارد:

1. آن را در همان مسیر پروژه باز کنید (پوشهٔ `wheels` ساخته می‌شود).
2. `START-WINDOWS.bat` را اجرا کنید؛ پیام
   «نصب آفلاین کتابخانه‌ها از پوشه wheels» را می‌بینید و با پایتون سیستم
   (۳.۱۲ / ۳.۱۳ / ۳.۱۴) نصب انجام می‌شود.

اگر هنوز هم خطا داد، در همان پنجرهٔ سیاه این را بزنید:

```
python -m pip install --no-index --find-links wheels -r backend\requirements.txt
```

یا اگر پایتون سیستم ندارید، از حالت پروکسی استفاده کنید:

```
set HTTP_PROXY=http://127.0.0.1:10809
set HTTPS_PROXY=http://127.0.0.1:10809
python -m pip install -r backend\requirements.txt
```

## ساخت مجدد پوشهٔ wheels (روی هر سیستمی با اینترنت سالم)

```
cd C:\faktorkhan
tools\prepare-wheels.bat
```

کتابخانه‌ها برای پایتون ۳.۱۲، ۳.۱۳ و ۳.۱۴ دانلود می‌شوند.
نسخه‌های دقیق و تست‌شده در `backend/requirements.lock.txt` ثبت شده‌اند.
