# نصب آفلاین فاکتورخوان روی ویندوز (بدون نیاز به اینترنت)

این راهنما برای وقتی است که `START-WINDOWS.bat` در مرحلهٔ **۳/۴** با خطای
`Read timed out` یا `No matching distribution found` متوقف می‌شود؛ یعنی
کامپیوتر به `pypi.org` دسترسی ندارد (فیلترینگ، پروکسی، اینترنت ضعیف یا شبکهٔ اداری).

فاکتورخوان برای اجرا به چند کتابخانه پایتون نیاز دارد. کافی است **یک‌بار** این
کتابخانه‌ها را به شکل فایل‌های آماده (`wheels`) کنار پروژه بگذاریم؛ بعد از آن نصب
**کاملاً آفلاین** و در حدود ۳۰ ثانیه انجام می‌شود.

---

## گام ۱ — بستهٔ آفلاین را بگیرید

فایل **`faktorkhan-1.0.0-WINDOWS-OFFLINE.zip`** (حدود ۲۳ مگابایت) را دانلود کنید.

این فایل شامل دو چیز است:

```
faktorkhan\
├── START-WINDOWS.bat
├── wheels\          ← کتابخانه‌های آمادهٔ ویندوز (۴۶ فایل)
│   ├── fastapi-0.162.2-py3-none-any.whl
│   ├── pydantic_core-2.50.4-cp312-cp312-win_amd64.whl
│   └── …
└── بقیهٔ پروژه
```

> کتابخانه‌ها برای **پایتون ۳.۱۲، ۳.۱۳ و ۳.۱۴** (۶۴ بیتی ویندوز) داخل بسته هستند.
> اگر نسخهٔ پایتون شما ۳.۱۱ است، پیام انتهای همین راهنما را ببینید.

---

## گام ۲ — از حالت فشرده خارج کنید

- روی فایل زیپ کلیک راست → **Extract All**
- مقصد: همان جایی که پروژه را گذاشته‌اید، معمولاً `C:\`
- اگر پرسید «فایل‌ها جایگزین شوند؟» → **بله** (فایل‌های کد یکسان هستند و
  پوشهٔ دادهٔ شما `storage\` دست نمی‌خورد)

بعد از این کار باید این مسیر را ببینید:

```
C:\faktorkhan\wheels\        ← پوشه wheels کنار START-WINDOWS.bat
```

---

## گام ۳ — اجرا

روی **`C:\faktorkhan\START-WINDOWS.bat`** دوبار کلیک کنید.

اسکریپت خودش تشخیص می‌دهد پوشهٔ `wheels` وجود دارد و می‌نویسد:

```
[۳/۴] نصب آفلاین کتابخانه‌ها از پوشه wheels  (بدون نیاز به اینترنت) ...
[۳/۴] کتابخانه‌ها آماده هستند.
```

سپس برنامه مثل همیشه روی `http://127.0.0.1:8000` بالا می‌آید.
از این پس **هیچ‌وقت** برای اجرا به اینترنت نیاز ندارید.

> 🔸 بار اول اینترنت لازم نیست؛ حتی نصب هم آفلاین است.
> 🔸 فقط خوانش ابری (OCR آنلاین) به اینترنت نیاز دارد؛ خوانش لوکال و بقیهٔ برنامه آفلاین کار می‌کند.

---

## اگر پایتون شما ۳.۱۱ (یا ۳.۱۵) است

بستهٔ آفلاین نسخه‌های ۳.۱۲ تا ۳.۱۴ را پوشش می‌دهد. دو راه دارید:

**راه اول (پیشنهادی):** پایتون ۳.۱۲ را از
`https://www.python.org/downloads/release/python-31210/`
نصب کنید و در صفحهٔ اول تیک **Add python.exe to PATH** را بزنید.

**راه دوم:** پوشهٔ `wheels` را خودتان برای نسخهٔ خودتان بسازید:

```
cd C:\faktorkhan
python -m pip download --no-deps --only-binary=:all: --platform win_amd64 ^
   --implementation cp --python-version 3.11 -r backend\requirements.lock.txt -d wheels
```

یا به‌سادگی روی یک کامپیوتر با اینترنت سالم (مثلاً سرور):

```
cd C:\faktorkhan
tools\prepare-wheels.bat
```

این فایل کتابخانه‌ها را برای ۳.۱۲، ۳.۱۳ و ۳.۱۴ دانلود می‌کند. اگر نسخهٔ دیگری
می‌خواهید، عدد نسخه را در فایل `tools\prepare-wheels.bat` عوض کنید (خط `for %%P in (...)`).

## اگر اینترنت دارید ولی `pypi.org` باز نمی‌شود

`START-WINDOWS.bat` خودش چند منبع را به‌ترتیب امتحان می‌کند:

1. `https://pypi.org/simple`
2. `https://mirror-pypi.runflare.com/simple`
3. `https://pypi.tuna.tsinghua.edu.cn/simple`
4. `https://mirrors.aliyun.com/pypi/simple`
5. `https://mirrors.cloud.tencent.com/pypi/simple`

اگر هر کدام جواب داد، نصب ادامه پیدا می‌کند. برای امتحان دستی یک آینه:

```
cd C:\faktorkhan
venv\Scripts\python.exe -m pip install -r backend\requirements.txt ^
    -i https://mirror-pypi.runflare.com/simple --timeout 60
```

اگر پشت پروکسی شرکت/دانشگاه هستید، اول این دو خط را در همان پنجرهٔ سیاه بزنید
و بعد اسکریپت را دوباره اجرا کنید:

```
set HTTP_PROXY=http://proxy.company.local:8080
set HTTPS_PROXY=http://proxy.company.local:8080
```

## پرسش‌های رایج

| پرسش | پاسخ |
|---|---|
| بستهٔ آفلاین را باید به مشتری هم بدهم؟ | نه. مشتری نسخهٔ **Setup.exe** را می‌گیرد که پایتون و کتابخانه‌ها داخلش هست. این بسته فقط برای اجرای نسخهٔ پایتونی روی سیستم خودتان/سرور است. |
| پوشهٔ `wheels` را می‌توانم پاک کنم؟ | بعد از نصب موفق بله (حدود ۲۳ مگابایت). ولی نگه داشتنش برای نصب مجدد یا نصب روی سیستم دیگر راحت‌تر است. |
| این کتابخانه‌ها امن هستند؟ | همه از مخزن رسمی PyPI و نسخه‌های دقیق و تست‌شده در `backend/requirements.lock.txt` هستند. |
| نصب آفلاین چقدر طول می‌کشد؟ | حدود ۲۰ تا ۴۰ ثانیه (بدون دانلود). |
| فایل `install-log.txt` چیست؟ | اگر نصب آنلاین خطا بدهد، اسکریپت متن کامل خطا را در این فایل می‌گذارد تا برای پشتیبانی بفرستید. |
