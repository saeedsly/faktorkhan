# راهنمای نصب و راه‌اندازی فاکتورخوان

**نسخه ساده و مرحله‌به‌مرحله — از صفر تا اولین فاکتور خوانده‌شده**

این راهنما فرض می‌کند هیچ چیزی روی سیستم شما نصب نیست. هر گام دقیقاً می‌گوید چه کاری
انجام دهید، چه چیزی تایپ کنید و **چه چیزی باید ببینید**. اگر خروجی شما با آنچه نوشته شده
فرق داشت، به بخش «مشکلات رایج» (بخش ۸) بروید.

سه مسیر مستقل دارید. فقط **یکی** را انتخاب کنید.

| مسیر | برای چه کسی | چقدر طول می‌کشد | چه چیزی لازم دارد |

## گام ۲: نصب پایتون

1. به این نشانی بروید: **https://www.python.org/downloads/windows/**

کلید `Win + R` را بزنید، تایپ کنید `cmd` و Enter. در پنجره سیاه بنویسید:

**باید ببینید:** چیزی شبیه این:

```
Python 3.12.7
```

اگر نوشت `python is not recognized`، یعنی تیک `Add to PATH` را نزده‌اید. راه سریع:
پایتون را حذف و دوباره با تیک نصب کنید.

## گام ۳: اجرای برنامه

روی فایل **`START-WINDOWS.bat`** دوبار کلیک کنید.

پنجره سیاهی باز می‌شود که این مراحل را خودش انجام می‌دهد:

| مرحله | چه اتفاقی می‌افتد | چقدر طول می‌کشد |
|---|---|---|
| ۱/۴ | بررسی نصب پایتون | چند ثانیه |
| ۲/۴ | ساخت محیط اجرا (`venv`) | حدود ۳۰ ثانیه |
| ۳/۴ | نصب کتابخانه‌ها (نیاز به اینترنت) | ۱ تا ۳ دقیقه |
| ۴/۴ | ساخت فایل تنظیمات `.env` | چند ثانیه |

سپس این پیام را می‌بینید:

```
================================================================
  برنامه در حال اجراست:   http://127.0.0.1:8000
  اطلاعات ورود اولیه در این فایل است:
     storage\OWNER-CREDENTIALS.txt
  برای توقف برنامه:  Ctrl + C   یا بستن این پنجره
================================================================
INFO:     Uvicorn running on http://127.0.0.1:8000
```

> 🔸 اگر اینترنت ندارید یا مرحلهٔ ۳/۴ با خطای اینترنت متوقف شد: از **بستهٔ کامل ویندوز**
> `faktorkhan-1.0.0-WINDOWS-PORTABLE.zip` استفاده کنید — پایتون و کتابخانه‌ها داخل خودش هستند
> و هیچ اتصالی لازم نیست. جزئیات: `docs/OFFLINE-INSTALL-FA.md`

> 🔸 این پنجره سیاه را **نبندید**؛ تا وقتی باز است برنامه فعال است.
> 🔸 بار اول اینترنت لازم است (برای نصب کتابخانه‌ها). بعد از آن، برنامه **آفلاین** کار می‌کند.

> 🔸 همه داده‌های شما در پوشه `C:\faktorkhan\storage\` ذخیره می‌شود:
> `storage\faktorkhan.db` پایگاه داده، `storage\uploads\` فایل‌های بارگذاری‌شده و
> `storage\exports\` فایل‌های خروجی. برای پشتیبان‌گیری فقط همین پوشه را کپی کنید.

**باید ببینید:** مرورگر خودش باز می‌شود و صفحه ورود فاکتورخوان نمایش داده می‌شود.
اگر باز نشد، خودتان مرورگر را باز کنید و آدرس `http://127.0.0.1:8000` را بزنید.

## گام ۴: پیدا کردن نام کاربری و رمز عبور

در پوشه پروژه به این مسیر بروید:

```
C:\faktorkhan\storage\OWNER-CREDENTIALS.txt
```

این فایل را با Notepad باز کنید. چیزی شبیه این داخلش است:

```
فاکتورخوان — اطلاعات ورود مالک سامانه
====================================
ایمیل: owner@faktorkhan.local
گذرواژه: Fk-WhtBfSY6-0dn
```

از **همین دو مقدار** برای ورود استفاده کنید:

| فیلد صفحه ورود | مقدار |
|---|---|
| ایمیل | `owner@faktorkhan.local` |
| گذرواژه | همان چیزی که در فایل است (مثلاً `Fk-WhtBfSY6-0dn`) |

دکمه **«ورود به سامانه»** را بزنید.

**باید ببینید:** داشبورد با منوی سمت راست (داشبورد، خوانش فاکتور، فاکتورها، گزارش‌ها…).
این یعنی همه چیز درست است. 🎉

> نکته: در ویدیوها/تصاویر دمو ممکن است چند فاکتور نمونه ببینید. در نصب تمیز شما داشبورد خالی است.

## گام ۵: تغییر رمز عبور (۲ دقیقه — حتماً انجام دهید)

1. منوی سمت راست → **تنظیمات**
2. زبانه **امنیت**
3. گذرواژه فعلی = همان رمزِ فایل
4. گذرواژه جدید را دو بار وارد کنید (حداقل ۸ کاراکتر)
5. **تغییر گذرواژه**

سپس فایل `storage\OWNER-CREDENTIALS.txt` را **پاک کنید** (یا در جای امن نگه دارید).

## گام ۶: فعال کردن خوانش ابری (توکن مخفی)

بدون این گام، برنامه فقط با موتور **لوکال** کار می‌کند (PDF متنی). برای فاکتورهای
دست‌نویس، حرارتی و عکس، موتور ابری لازم است.

### ۶-۱. آدرس درگاه را در تنظیمات برنامه بگذارید

1. در پوشه `C:\faktorkhan` فایل `.env` را با **Notepad** باز کنید
   (اگر نمی‌بینید: در Explorer از منوی View گزینه Hidden items را روشن کنید).
2. خط مربوط به درگاه را پیدا کنید و آدرس خودتان را در آن بنویسید:

   ```env
   CLOUD_OCR_GATEWAY=https://www.eboo.ir/api/ocr/getway
   ```

3. فایل را ذخیره کنید.
4. پنجره سیاه (`START-WINDOWS.bat`) را ببندید و **دوباره اجرا کنید** تا تنظیمات خوانده شود.

> 🔒 این آدرس فقط در همین فایل روی سیستم شماست. در هیچ صفحه‌ای از برنامه، در هیچ پاسخ
> API و در هیچ لاگی نمایش داده نمی‌شود.

### ۶-۲. توکن را وارد کنید

1. منوی سمت راست → **پنل مدیریت**
2. زبانه **سرویس ابری**
3. در کادر «جایگزینی توکن» توکن را Paste کنید → **ذخیره توکن**
4. دکمه **تست اتصال و اعتبار** را بزنید

**باید ببینید:**

```
✓ ارتباط با سرویس ابری برقرار است — اعتبار OCR: 842 صفحه
توکن ثبت‌شده: بله
طول توکن: 32
اثر انگشت مخفی: ••••••••••••a1b2
```

از این لحظه، مقدار واقعی توکن **هیچ‌جا نمایش داده نمی‌شود** — نه در این صفحه، نه در
پایگاه داده به‌صورت خام (رمزنگاری‌شده است)، نه در لاگ. اگر خواستید عوضش کنید، فقط
توکن جدید را در همان کادر ثبت کنید.

**باید ببینید:** در نوار بالای برنامه، کنار آیکن ابر، اعتبار سرویس نمایش داده می‌شود.

## گام ۷: تست عملی — یک فاکتور بخوانید

1. منوی سمت راست → **خوانش فاکتور**
2. فایل یک فاکتور (PDF یا عکس) را با ماوس داخل کادر بکشید و رها کنید
3. موتور **سرویس ابری** انتخاب باشد (اگر توکن را ثبت کرده باشید، فعال است)
4. روش تبدیل: **۴ — استخراج متن (پیشنهادی)**
5. **شروع خوانش فاکتور**

**باید ببینید:** نوار پیشرفت با این مراحل:

```
✓ در صف پردازش  →  ✓ ارسال فایل  →  ⟳ تبدیل و خوانش متن  →  ✓ آماده بازبینی
```

سپس فرم بازبینی با **امتیاز اعتماد** و فیلدهای پرشده باز می‌شود:

- شماره فاکتور، تاریخ، فروشنده، خریدار، جمع اقلام، مالیات، مبلغ کل
- جدول اقلام (قابل ویرایش)
- هشدارها (مثلاً «جمع اقلام با مبلغ کل اختلاف دارد»)

فیلدها را کنترل کنید و **ثبت فاکتور** را بزنید.

**باید ببینید:** پیام «فاکتور با موفقیت ثبت شد» و رفتن به صفحه جزئیات فاکتور.

> اگر امتیاز اعتماد پایین بود (زیر ۵۰٪)، فایل تار یا کج بوده؛ با عکس واضح‌تر تست کنید.

# مسیر ۲ — ساخت فایل نصبی `Setup.exe`

پوشه `C:\faktorkhan\desktop` را باز کنید و روی **`build_windows.bat`** دوبار کلیک کنید.

**چقدر طول می‌کشد:** ۵ تا ۱۰ دقیقه.

# مسیر ۳ — سرور با MySQL (WAMP) برای چند کاربر

> ⚡ راه سریع‌تر: دو فایل **`SETUP-MYSQL-WINDOWS.bat`** و **`START-SERVER-WINDOWS.bat`**
> همین کارهای زیر را خودکار انجام می‌دهند. راهنمای گام‌به‌گام سه سناریو:
> `docs/DEPLOY-WINDOWS-WAMP.md`



این مسیر وقتی است که می‌خواهید چند نفر از راه دور با مرورگر کار کنند.

## گام ۱: نصب پیش‌نیازها

- **WAMP** (یا XAMPP): از `wampserver.com` — نصب معمولی.
- **Python 3.11+** با تیک `Add to PATH`.

بررسی:

```bat
python --version
```

و مطمئن شوید آیکن WAMP در نوار وظیفه **سبز** است (Apache و MySQL روشن).

## گام ۲: ساخت پایگاه داده

1. روی آیکن WAMP کلیک کنید → **phpMyAdmin**
2. زبانه **Databases** → نام: `faktorkhan` → Collation: `utf8mb4_persian_ci` → Create
3. تمام. (جداول خودکار ساخته می‌شوند)

> یا از خط فرمان:
> ```bat
> mysql -u root -e "CREATE DATABASE faktorkhan CHARACTER SET utf8mb4 COLLATE utf8mb4_persian_ci;"
> ```

## گام ۳: فایل تنظیمات `.env`

فایل `C:\faktorkhan\.env` را باز کنید و این مقادیر را تنظیم کنید:

```env
# ── امنیت (اجباری) ──
SECRET_KEY=اینجا-یک-مقدار-تصادفی-بلند
ENCRYPTION_KEY=اینجا-یک-مقدار-تصادفی-دیگر

# ── پایگاه داده ──
DATABASE_URL=mysql+pymysql://root:@127.0.0.1:3306/faktorkhan?charset=utf8mb4

# ── سرویس ابری (فقط همین‌جا) ──
CLOUD_OCR_GATEWAY=https://www.eboo.ir/api/ocr/getway

# ── حساب مالک ──
OWNER_NAME=سعید سالاری
OWNER_EMAIL=me@example.com
OWNER_PASSWORD=یک-رمز-قوی-حداقل-۸-کاراکتر

# ── اجرا ──
HOST=0.0.0.0
PORT=8000
```

### ساخت مقدار تصادفی برای کلیدها

پنجره `cmd` را باز کنید و **دو بار** این دستور را اجرا کنید (هر بار یک مقدار می‌دهد):

```bat
python -c "import secrets;print(secrets.token_urlsafe(48))"
```

هر خروجی را در یکی از دو خط `SECRET_KEY` و `ENCRYPTION_KEY` بگذارید.

> 🔸 اگر رمز root در MySQL دارید: `mysql+pymysql://root:رمز@127.0.0.1:3306/...`
> 🔸 `HOST=0.0.0.0` یعنی سایر دستگاه‌های شبکه هم می‌توانند وصل شوند.

## گام ۴: نصب وابستگی‌ها

```bat
cd C:\faktorkhan
python -m venv venv
venv\Scripts\activate
pip install -r backend\requirements.txt
```

## گام ۵: اجرای برنامه

```bat
cd C:\faktorkhan\backend
python run.py --no-browser
```

**باید ببینید:**

```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

حالا از هر دستگاهی در شبکه:

```
http://آی‌پی-سرور:8000
```

آی‌پی سرور را با دستور `ipconfig` ببینید (مثلاً `192.168.1.20`).

اگر ویندوز فایروال هشدار داد، **Allow access** را بزنید.

## گام ۶ (اختیاری): آدرس تمیز با Apache

می‌خواهید به‌جای `http://192.168.1.20:8000` آدرس `http://faktorkhan.local` داشته باشید؟

1. فایل `deploy\apache\faktorkhan.conf` را باز کنید و مسیر `DocumentRoot` را با مسیر
   واقعی خودتان جایگزین کنید.
2. آن را در `C:\wamp64\bin\apache\apache2.4.x\conf\extra\httpd-vhosts.conf` کپی کنید.
3. در `C:\Windows\System32\drivers\etc\hosts` این خط را اضافه کنید:

   ```
   127.0.0.1   faktorkhan.local
   ```

4. Apache را Restart کنید.

## گام ۷: اجرای خودکار با ویندوز

می‌خواهید بعد از ری‌استارت، برنامه خودش بالا بیاید؟ از **NSSM** استفاده کنید:

```bat
nssm install FactorKhan "C:\faktorkhan\venv\Scripts\python.exe" "C:\faktorkhan\backend\run.py --no-browser"
```

# بخش ۵ — فروش اشتراک: سناریوی کامل

فرض کنید مشتری «شرکت پارس» اشتراک یک‌ساله می‌خواهد:

### ۱) کد بسازید (شما)

```
پنل مدیریت → کدهای اشتراک
  طرح      : حرفه‌ای یک‌ساله
  تعداد    : ۱
  یادداشت  : شرکت پارس - سفارش ۱۰۲
  → ساخت کدها
```

خروجی چیزی شبیه این است:

```
FK-7K4M-9QXA-3DTU-H2NR-4C
```

روی **«کپی همه کدها»** بزنید و در فایل امن ذخیره کنید (این تنها باری است که نمایش داده می‌شود).

### ۲) کد را به مشتری بدهید

> «در صفحه **اشتراک من**، کد را وارد کنید و فعال‌سازی اشتراک را بزنید.»

### ۳) مشتری فعال می‌کند

```
اشتراک من → کد اشتراک → FK-7K4M-... → فعال‌سازی اشتراک
```

از این لحظه:

- ۳۶۵ روز اعتبار
- ۲۰٬۰۰۰ صفحه سهمیه
- پشتیبانی یک‌ساله
- دو دستگاه مجاز

### ۴) تمدید سال بعد

کد جدید می‌سازید، مشتری روی همان حساب فعال می‌کند؛ روزهای جدید **به باقی‌مانده اضافه** می‌شود.

> 💡 کد هرگز دو بار کار نمی‌کند. اگر مشتری کد را گم کرد، شما در فهرست کدها می‌بینید که
> «استفاده‌شده» است یا نه.

# بخش ۸ — مشکلات رایج و راه‌حل

| پیام / مشکل | علت | راه‌حل |
|---|---|---|
| `python is not recognized` | تیک Add to PATH زده نشده | پایتون را حذف و با تیک نصب کنید |
| `[خطا] نصب کتابخانه‌ها ناموفق بود` یا `Read timed out` | دسترسی نداشتن به pypi.org | **بستهٔ کامل ویندوز** (`faktorkhan-1.0.0-WINDOWS-PORTABLE.zip`) را در `C:\` باز کنید؛ پایتون و کتابخانه‌ها داخلش هستند — راهنمای کامل: `docs/OFFLINE-INSTALL-FA.md` |
| صفحه سفید در مرورگر | برنامه اجرا نشده | پنجره `START-WINDOWS.bat` باز و سبز است؟ |
| `Address already in use` | پورت ۸۰۰۰ اشغال است | `START-WINDOWS.bat` را ببندید یا `--port 8010` |
| `Access denied for user 'root'` | رمز MySQL | رمز را در `DATABASE_URL` درست کنید |
| متن فارسی به‌صورت `????` | کدگذاری DB | دیتابیس را با `utf8mb4_persian_ci` بسازید |
| `ModuleNotFoundError: pymysql` | نصب ناقص | `pip install -r backend\requirements.txt` |
| «سرویس ابری آماده نیست» | توکن ثبت نشده یا درگاه تنظیم نشده | گام ۶ مسیر ۱ را انجام دهید |
| «اعتبار سرویس ابری کافی نیست» | شارژ پنل ابری | اعتبار را شارژ کنید |
| خطای ۴۱۳ هنگام آپلود | حجم فایل | `MAX_UPLOAD_MB` در `.env` را بالا ببرید |
| «اشتراک شما منقضی شده است» | کد فعال نشده | اشتراک من → وارد کردن کد |
| ورود ناموفق مکرر → قفل | ۷ تلاش اشتباه | ۱۵ دقیقه صبر کنید یا رمز را ریست کنید |
| توکن را گم کردم | نمایش داده نمی‌شود (طبق طراحی) | توکن جدید از پنل ابری بگیرید و ثبت کنید |

### دیدن لاگ خطاها

- پنجره `START-WINDOWS.bat` همیشه آخرین خطاها را نشان می‌دهد؛ آن را بالا/پایین اسکرول کنید.
- در نسخه نصبی: فایل `%APPDATA%\FactorKhan\desktop.log`
- سلامت سامانه: آدرس `http://127.0.0.1:8000/api/system/health`
