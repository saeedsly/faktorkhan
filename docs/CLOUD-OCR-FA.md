# فعال‌کردن خوانش ابری — فقط با توکن (بدون آدرس درگاه)

## خلاصه

**آدرس درگاه از قبل داخل برنامه است.** لازم نیست در `.env` چیزی بنویسید.
فقط توکن را در یکی از دو راه زیر ثبت کنید، تا موتور ابری برای فاکتورهای
دست‌نویس، حرارتی و عکس فعال شود.

| راه | مناسب برای | زمان |
|---|---|---|
| پنل مدیریت → سرویس ابری | کار روزمره با مرورگر | ۳۰ ثانیه |
| `SET-CLOUD-TOKEN-WINDOWS.bat` | نصب تازه، سرور بدون مرورگر، اسکریپت | ۲۰ ثانیه |

هر دو یک کار می‌کنند: توکن را **رمزنگاری‌شده** در پایگاه ذخیره می‌کنند و هیچ‌جا
نمایش نمی‌دهند.

---

## راه ۱ — از پنل مدیریت (پیشنهادی)

1. برنامه را اجرا کنید (`START-WINDOWS.bat` یا `START-SERVER-WINDOWS.bat`).
2. با حساب مالک وارد شوید.
3. منوی راست → **پنل مدیریت** → زبانهٔ **سرویس ابری**.
4. توکن را در کادر «جایگزینی توکن» بچسبانید → **ذخیره توکن**.
5. **تست اتصال و اعتبار** را بزنید.

خروجی درست:

```
✓ ارتباط با سرویس ابری برقرار است — اعتبار OCR: 842 صفحه
درگاه سمت سرور        پیکربندی‌شده
توکن ذخیره‌شده        بله
اثر انگشت مخفی        ••••••••••••a1b2
```

> توکن **بعد از ذخیره دیگر قابل مشاهده نیست**؛ اگر آن را گم کردید، فقط می‌توانید
> توکن جدید ثبت کنید یا آن را حذف کنید.

---

## راه ۲ — از خط فرمان (بدون مرورگر)

```
SET-CLOUD-TOKEN-WINDOWS.bat
```

توکن را می‌پرسد، در تایپ هیچ کاراکتری نشان نمی‌دهد، ذخیره می‌کند و بعد
اتصال را تست می‌کند.

دستورهای دیگر:

```
SET-CLOUD-TOKEN-WINDOWS.bat --check     ← وضعیت (بدون تغییر)
SET-CLOUD-TOKEN-WINDOWS.bat --test      ← تست اتصال و اعتبار
SET-CLOUD-TOKEN-WINDOWS.bat --clear     ← حذف توکن
```

معادل پایتونی (اگر داخل محیط برنامه هستید):

```
python tools\set_cloud_token.py
```

## نتیجه

پس از ثبت توکن:

- کارت **سرویس ابری** در صفحهٔ «خوانش فاکتور» برچسب **آماده** می‌گیرد.
- موتور ابری برای همهٔ کاربران فعال می‌شود (نه فقط شما).
- اعتبار مصرفی صفحه‌به‌صفحه از حساب سرویس‌دهنده کم می‌شود؛ با دکمهٔ
  **به‌روزرسانی اعتبار** در پنل مدیریت آن را ببینید.

## اگر خطا گرفتید

| پیام | معنا | راه‌حل |
|---|---|---|
| «توکن معتبر نیست» | کمتر از ۸ کاراکتر | توکن کامل را کپی کنید (بدون فاصله یا خط جدید) |
| «فایل با توکن ارسالی یافت نشد» (TokenNotFound) | توکن اشتباه یا باطل شده | توکن را از پنل سرویس‌دهنده دوباره بگیرید |
| «اعتبار سرویس ابری کافی نیست» | اعتبار تمام شده | حساب سرویس‌دهنده را شارژ کنید |
| «سرویس ابری پاسخ نداد (اتمام زمان)» | اینترنت کند یا فایل بزرگ | دوباره تلاش کنید؛ فایل را کوچک‌تر کنید |
| «ارتباط با سرویس ابری برقرار نشد» | فایروال/پروکسی | اینترنت سرور را بررسی کنید؛ پورت ۴۴۳ باید باز باشد |
| «خطا در فایل ارسالی» (FileCorrupted) | فایل خراب/رمزدار | فایل را باز کنید و دوباره ذخیره کنید |

> اگر شبکه‌تان پروکسی اجباری دارد، در ویندوز متغیرهای
> `HTTPS_PROXY` و `HTTP_PROXY` را تنظیم کنید و برنامه را دوباره اجرا کنید.

## پرسش‌های رایج

**آدرس درگاه را از کجا پیدا کنم؟**
پیدا کردنش لازم نیست — داخل برنامه است. اگر سرویس‌دهنده آدرس دیگری اعلام کرد،
می‌توانید در `.env` خط `CLOUD_OCR_GATEWAY=<آدرس جدید>` را بنویسید و برنامه را
ری‌استارت کنید. این مقدار هم در هیچ صفحه‌ای نمایش داده نمی‌شود.

**آیا توکن در فایل `.env` لازم است؟**
نه. اولویت با پنل مدیریت است. `CLOUD_OCR_SEED_TOKEN` فقط برای نصب‌های خودکار است
و آن هم رمزنگاری‌شده ذخیره می‌شود.

**اگر توکن عوض شد چه؟**
توکن جدید را ثبت کنید؛ مقدار قبلی بازنویسی می‌شود. کارهای در حال اجرا با توکن
قدیمی تمام می‌شوند.

**چند کاربر می‌توانند استفاده کنند؟**
همهٔ کاربران از همان توکن سرویس استفاده می‌کنند؛ مصرف اعتبار بین آن‌ها مشترک است.
