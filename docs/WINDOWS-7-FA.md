# فاکتورخوان روی ویندوز ۷ — چه نسخه‌ای، چه‌کار کنم

## خلاصه: دو بسته دارید، یکی برای ویندوز ۷ است

| بسته | ویندوز ۷ | ویندوز ۸.۱/۱۰/۱۱ |
|---|---|---|
| `faktorkhan-1.0.0-WINDOWS-PORTABLE.zip` (پایتون همراه) | ❌ **اجرا نمی‌شود** | ✅ |
| `FactorKhan-Setup.exe` (نسخهٔ رومیزی) | ✅ | ✅ |
| `faktorkhan-v1.0.0.zip` با پایتون ۳.۸ روی سیستم | ✅ | ✅ |

**دلیل:** پایتون ۳.۹ به بعد روی ویندوز ۷ اجرا نمی‌شود. بستهٔ PORTABLE یک
پایتون ۳.۱۳ همراه دارد، پس روی ویندوز ۷ خطا می‌دهد. نسخهٔ رومیزی با پایتون ۳.۸
ساخته شده که آخرین نسخهٔ سازگار با ویندوز ۷ است.

---

## راه ۱ (توصیه‌شده) — نسخهٔ رومیزی

1. `FactorKhan-Setup.exe` را روی ویندوز ۷ کپی و نصب کنید.
2. آیکن **فاکتورخوان** روی دسکتاپ می‌آید؛ دوبار کلیک.
3. مرورگر خودش باز می‌شود (`http://127.0.0.1:8000`).
4. با ایمیل و گذرواژه‌ای که در پایان نصب نشان داده می‌شود وارد شوید.

> اگر ویندوز ۷ شما **SP1** و `Universal C Runtime` را ندارد:
> [KB2999226](https://www.microsoft.com/en-us/download/details.aspx?id=49093) را نصب کنید.
> اکثر نسخه‌های ویندوز ۷ با آپدیت‌های معمول این را دارند.

---

## راه ۲ — همین کد را با پایتون ۳.۸ خودتان اجرا کنید

اگر می‌خواهید روی همان سیستم محل کار، بدون نصب چیزی، تست کنید:

1. **پایتون ۳.۸.۱۰ (۳۲ یا ۶۴ بیتی، مطابق ویندوزتان)** را نصب کنید:
   <https://www.python.org/downloads/release/python-3810/>
   → در نصب **Add Python 3.8 to PATH** را تیک بزنید.

2. فایل `faktorkhan-v1.0.0.zip` را در مثلاً `C:\faktorkhan` باز کنید.

3. `START-WINDOWS.bat` را دوبار کلیک کنید. این اسکریپت:
   - یک محیط مجازی می‌سازد
   - کتابخانه‌ها را نصب می‌کند (اینترنت لازم است، یک‌بار)
   - برنامه را اجرا می‌کند و مرورگر را باز می‌کند

4. اگر کتابخانه‌ها را از قبل دارید (`wheels` در بستهٔ OFFLINE)، اینترنت لازم نیست.

> ⚠️ پایتون نسخهٔ ۳.۸ **حداقل** است. پایتون ۳.۹+ روی ویندوز ۷ نصب نمی‌شود.

---

## آیا سریع‌ترین راه تست نیست؟ — بله

اگر فقط می‌خواهید ببینید برنامه چه شکلی است، **لازم نیست روی ویندوز ۷ نصبش کنید.**
از یک سیستم ویندوز ۱۰/۱۱ یا همان صفحهٔ پیش‌نمایش وب استفاده کنید و بعداً روی
ویندوز ۷ نسخهٔ رومیزی را نصب کنید.

---

## خطاهای رایج روی ویندوز ۷

| خطا | علت | راه‌حل |
|---|---|---|
| `api-ms-win-core-path-l1-1-0.dll` پیدا نشد | پایتون ۳.۹+ | از نسخهٔ رومیزی یا پایتون ۳.۸ استفاده کنید |
| `The program can't start because VCRUNTIME140.dll` | نبود Visual C++ | [VC++ 2015-2022 Redistributable](https://aka.ms/vs/17/release/vc-redist.x86.exe) را نصب کنید |
| `Unsupported Python version` | نسخهٔ پایتون جدید | پایتون ۳.۸.۱۰ نصب کنید |
| `SSL: CERTIFICATE_VERIFY_FAILED` | گواهی‌های قدیمی ویندوز ۷ | ویندوز را آپدیت کنید یا `CLOUD_OCR_VERIFY_TLS=false` بگذارید (فقط برای تست) |
| مرورگر باز نمی‌شود | IE قدیمی | Chrome/Firefox نسخهٔ سازگار با ویندوز ۷ را نصب کنید |

> ⚠️ **توجه:** ویندوز ۷ دیگر پشتیبانی امنیتی نمی‌گیرد. برای استفادهٔ **اینترنتی**
> حتماً از ویندوز ۱۰/۱۱ یا ویندوز سرور استفاده کنید. ویندوز ۷ فقط برای تست محلی.
