## راه نصب سریع (WAMP)

1. `faktorkhan-php-htdocs.zip` را دانلود کنید.
2. محتوای آن را در `C:\wamp64\www\faktorkhan\` بریزید (سه فایل: `index.php`، `.htaccess`، `config.sample.php`).
3. `http://localhost/faktorkhan/` را باز کنید.
4. گذرواژهٔ محلی بسازید → توکن را بچسبانید → «تست اعتبار» → فایل را آپلود کنید.

راهنمای کامل: [`docs/PHP-HTTPDOCKS-FA.md`](../docs/PHP-HTTPDOCKS-FA.md)

## نسخهٔ کامل ویندوز (ویندوز ۱۰/۱۱)

بستهٔ PORTABLE (۳۵ مگابایت، پایتون همراه) در مخزن گیت قابل نگه‌داری نیست؛
از پوشهٔ کاری Arena یا از `START-WINDOWS.bat` روی همان نسخهٔ سورس استفاده کنید.
