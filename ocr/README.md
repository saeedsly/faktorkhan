# فاکتورخوان — OCR فارسی در مرورگر + سیستم تست دقت

این بخش یک نسخه‌ی وب است که روی **هر سیستمی با مرورگر مدرن** اجرا می‌شود.
OCR کاملاً داخل مرورگر انجام می‌شود و فایل فاکتور به سرور فرستاده نمی‌شود.

## اجرا

```bash
cd ocr
npm install            # وابستگی‌ها (tesseract.js + داده‌ی فارسی)
npm run install:vendor # کپی فایل‌های مرورگری به public/vendor
npm run serve          # http://localhost:8000  (روی 0.0.0.0 هم گوش می‌دهد)
```

## سیستم تست دقت

1. نمونه‌های ساختگی با جواب درست بسازید (از ریشه‌ی ریپو):
   ```bash
   python ocr/eval/generate_samples.py 30
   ```
   فاکتورها با همان سرویس و قالب برنامه ساخته می‌شوند، بنابراین جواب درست دقیق است.
2. تست را اجرا کنید:
   ```bash
   cd ocr && npm run eval
   ```
   گزارش در `eval/report.json` ذخیره می‌شود. معیارها:
   - دقت هر فیلد (شماره، تاریخ، جمع اقلام، تخفیف، مشمول مالیات، مالیات، مبلغ قابل پرداخت)
   - درصد همه‌ی فیلدهای درست در هر فاکتور
   - بازیابی عددها و نام کالاها در متن
   - نرخ تشخیص خطا: چند درصد از فاکتورهای غلط توسط بررسی‌های حسابی علامت خوردند

## منطق

- `public/extract.js`: استخراج فیلدها و بررسی‌های حسابی (مشترک بین مرورگر و تست).
- بررسی‌های حسابی: `جمع اقلام − تخفیف = مشمول مالیات` و `مشمول مالیات + مالیات = قابل پرداخت`.
  اگر OCR یک رقم را غلط بخواند، معمولاً این بررسی‌ها شکست می‌خورند و فاکتور برای بازبینی علامت می‌خورد.

## محدودیت‌های فعلی

- موتور: Tesseract (مدل فارسی `best_int`). برای ارقام و جدول‌ها دقت کافی نیست؛ نتیجه‌ی تست در `eval/report.json` است.
- مدل‌های قوی‌تر مانند PaddleOCR-VL-1.6 یا GLM-OCR وزن‌های بزرگ دارند که از Hugging Face دانلود می‌شوند و در محیط توسعه‌ی فعلی در دسترس نیستند؛ برای نسخه‌ی بعدی باید روی سرور یا رایانه‌ی دارای اینترنت و GPU اجرا شوند.
