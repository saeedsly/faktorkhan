# فاکتورخان (faktorkhan)

نرم‌افزار ویندوزی صدور فاکتور با دو نوع فاکتور:

- **فاکتور دستی**: کاربر مشتری و اقلام را وارد می‌کند. ابتدا به‌صورت «پیش‌نویس» (قابل ویرایش) ذخیره می‌شود و با «صدور» شماره می‌گیرد (مثلاً `M-1405-0001`).
- **فاکتور سیستمی**: با یک عملیات صادر می‌شود؛ شماره و تاریخ امروز خودکار تعیین می‌شوند (مثلاً `S-1405-0001`) و پس از صدور قابل ویرایش نیست.

## ویژگی‌های دقت

- تمام محاسبات با `Decimal` انجام می‌شود؛ هیچ محاسبه‌ای با `float` انجام نمی‌شود.
- مبالغ به ریال کامل و با نیم به بالا گرد می‌شوند. گرد کردن برای هر ردیف انجام می‌شود و جمع فاکتور مجموع همان ردیف‌هاست.
- ترتیب محاسبه: `تعداد × قیمت واحد` ← تخفیف ← مالیات (درصد روی مبلغ پس از تخفیف).
- شماره‌ی فاکتور فقط هنگام صدور و داخل تراکنش دیتابیس گرفته می‌شود؛ شماره‌ها بدون شکاف‌اند و ابطال شماره را دوباره استفاده نمی‌کند.
- فاکتور صادرشده، اقلام آن و شماره‌اش توسط trigger دیتابیس قفل است (حتی اگر از خارج برنامه تغییر داده شود).
- تاریخ شمسی با اعتبارسنجی (مثلاً ۱۴۰۴/۱۲/۳۰ رد می‌شود).
- مبلغ به حروف فارسی و خروجی PDF با چیدمان راست‌به‌چپ.
- گزارش فروش بر اساس بازه‌ی شمسی (فقط فاکتورهای صادرشده؛ ابطال‌شده‌ها حذف می‌شوند).

## اجرا (توسعه)

```bash
python -m venv .venv
.venv\Scripts\activate          # ویندوز
pip install -r requirements-dev.txt
python run_faktorkhan.py
```

داده‌ها در `%APPDATA%\faktorkhan\faktorkhan.db` ذخیره می‌شوند. برای تغییر مسیر، متغیر محیطی `FAKTORKHAN_DB` را تنظیم کنید.

## تست

```bash
python -m pytest
```

## ساخت فایل exe برای ویندوز

- با GitHub Actions: هر push یا pull request، تست‌ها را اجرا و پوشه‌ی `faktorkhan-windows` (شامل `faktorkhan.exe`) را به‌عنوان artifact تولید می‌کند.
- به‌صورت محلی روی ویندوز:
  ```bash
  pyinstaller --noconfirm --windowed --name faktorkhan --collect-submodules faktorkhan run_faktorkhan.py
  ```

## ساختار

| مسیر | توضیح |
|---|---|
| `faktorkhan/money.py` | محاسبات مالی و قالب‌بندی مبلغ |
| `faktorkhan/fa.py` | ارقام فارسی و عدد به حروف |
| `faktorkhan/jalali.py` | تبدیل و اعتبارسنجی تاریخ شمسی |
| `faktorkhan/service.py` | قواعد صدور، ابطال، قفل و گزارش |
| `faktorkhan/db.py` | SQLite، شماره‌گذاری و triggerهای قفل |
| `faktorkhan/pdf.py` | خروجی PDF |
| `faktorkhan/ui/` | رابط PySide6 |
| `tests/` | تست‌های منطق، دیتابیس، رابط و PDF |
