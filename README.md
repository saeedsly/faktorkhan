# فاکتورخان (Faktorkhan)

نرم‌افزار دسکتاپ حرفه‌ای برای digitize کردن فاکتورهای دستی و حرارتی (فاکتور اتاقی) با دقت بالا و خروجی اکسل (Excel)، همراه با سیستم لایسنس/اشتراک و لایه امنیتی پیشرفته.

## امکانات کلیدی
- تشخیص متن فاکتورهای خط‌دستی و چاپی/حرارتی با پیش‌پردازش تصویر ( OpenCV )
- استخراج 필دهای فاکتور (شماره، تاریخ، مبلغ، مالیات، فروشنده، خریدار) و اقلام فاکتور
- xuất اکسل قالب‌بندی‌شده و حرفه‌ای
- رابط کاربری گرافیک احترافية (PyQt6) باتم dark theme
- سیستم لایسنس آفلاین با بصمہ ماشین (HWID)، امضا criptográfico و انقضا
- کلیگان لایسنس آنلاین (سرور اشتراک برای فروش اشتراک یک ساله با پشتیبانی)
- تاریخچه فاکتور‌ها در پایگاه داده SQLite
- تست‌های یکپارچه (pytest)

## نصب و اجرا
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

> تشخیص خط‌دستی در فاکتورهای حرارتی با backend `easyocr` بسیار دقیق‌تر است (نیاز به نصب `torch` دارد و وزنه ziemlich است). baclkend پیش‌فرض `tesseract` است که در صورت عدم وجود باینری tesseract، به حالت ت efecto degrade می‌شود.
